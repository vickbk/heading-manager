# Vitest PR Coverage Reporter & Summary Action

Automated coverage reporter and GitHub PR comment manager for Vitest. Parses `coverage-summary.json`, writes rich Markdown metrics to the GitHub Actions Step Summary, and posts or updates sticky coverage comments directly on Pull Requests without comment duplication.

---

## Key Features

- **Sticky PR Comments:** Detects previously posted coverage reports using a distinct marker and updates (`PATCH`) the existing comment rather than spamming the PR thread with new ones.
- **Native Step Summaries:** Automatically renders formatted Markdown tables directly into `$GITHUB_STEP_SUMMARY` for fast visibility in workflow runs.
- **Workflow Environment Exports:** Appends `TOTAL_PCT` statement coverage metrics to `$GITHUB_ENV` for downstream workflow step evaluation.
- **Zero External HTTP Dependencies:** Uses native standard `fetch` API and GitHub REST API headers (`application/vnd.github+json`).
- **Resilient Error Handling:** Fails gracefully on missing coverage files and provides actionable error logs on HTTP or network failures.

---

## Workflow Integration

Add the summary generator and PR comment runner to your GitHub Actions workflow file (e.g., `.github/workflows/test.yml`).

```yaml
name: Test & Coverage Report

on:
  pull_request:
    branches: [main, dev]

jobs:
  test-coverage:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pull-requests: write

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: "npm"

      - name: Install dependencies
        run: npm ci

      - name: Run Vitest with JSON Summary Coverage
        run: npx vitest run --coverage.reporter=json-summary

      - name: Generate Coverage Summary
        run: npx tsx src/generate-coverage-summary.ts

      - name: Post or Update PR Coverage Comment
        if: github.event_name == 'pull_request'
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          PR_NUMBER: ${{ github.event.number }}
        run: npx tsx src/comments/vitest/index.ts
```

## Architecture & Module Overview

```

├── scripts/
│   ├── coverage-summary.ts  # Generates workflow summary & exports TOTAL_PCT
│   ├── vitest.ts  #Posts comment summary
│   ├── index.ts                      # CLI entrypoint runner for posting/updating comments
│   ├── modules/
│   │   └── github-api/index.ts       # REST client for fetching & modifying PR comments
│   ├── utils/
│   │   ├── format.ts                 # Coverage row formatting utilities
│   │   └── report.ts                 # JSON report parser and Markdown table builder
│   └── types.ts                      # TypeScript interfaces for API & Coverage schemas
└── *.test.ts                         # Vitest unit test suite (100% spy-isolated)

```

### Module Responsibilities

1. **`generateCoverageSummary(summaryPath?)`**

- Reads the `coverage/coverage-summary.json` file generated by Vitest.
- Formats statement, branch, function, and line metrics into a GitHub Flavored Markdown table.
- Appends the output to `$GITHUB_STEP_SUMMARY`.
- Appends `TOTAL_PCT=<percentage>` to `$GITHUB_ENV`.

2. **`postCoverageComment()`**

- Reads repository parameters (`repository`, `prNumber`, `token`, `runId`).
- Queries GitHub's Issue Comments API for an existing PR comment matching `COMMENT_IDENTIFIER`.
- Performs a `POST` request if no comment exists, or a `PATCH` request if a comment ID is found.

## Environment Variables & Configuration

| Variable                   | Description                                                                                   | Required By           |
| -------------------------- | --------------------------------------------------------------------------------------------- | --------------------- |
| `GITHUB_TOKEN`             | GitHub API Token (`repo` / `pull-requests: write` permissions)                                | `postCoverageComment` |
| `GITHUB_STEP_SUMMARY`      | Absolute file path provided automatically by GitHub Runner for step summaries                 | `writeStepSummary`    |
| `GITHUB_ENV`               | Absolute file path provided automatically by GitHub Runner for workflow environment variables | `exportGithubEnv`     |
| `PR_NUMBER` / `GITHUB_REF` | Target Pull Request ID number                                                                 | `getGithubParams`     |

## Local Script Execution

You can run both scripts locally for testing or debugging:

```bash
# 1. Generate local coverage summary
npx tsx src/generate-coverage-summary.ts

# 2. Run PR comment runner (requires GITHUB_TOKEN & target repository environment variables)
GITHUB_TOKEN="ghp_xxx" GITHUB_REPOSITORY="owner/repo" PR_NUMBER=42 npx tsx src/comments/vitest/index.ts

```
